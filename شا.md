Direct3D 9 Programming Overview (Developer-Oriented Guide)
1. Introduction

Direct3D 9 is a graphics API that is part of Microsoft’s DirectX platform.

It provides a low‑level interface for interacting with the GPU to render 3D graphics and perform high‑performance rendering tasks.

Developers typically use Direct3D 9 for:

    Games
    Real‑time visualization
    Simulation software
    Legacy graphics engines

The API exposes hardware‑accelerated features such as vertex processing, texture mapping, lighting, and shader execution.
2. Basic Architecture

A typical Direct3D 9 application contains several core components:

    Direct3D Object
    Device
    Swap Chain / Back Buffer
    Vertex Buffers
    Index Buffers
    Textures
    Shaders

The rendering pipeline transforms geometry data into pixels displayed on the screen.
3. Creating the Direct3D Object

The first step in any Direct3D 9 program is creating the main Direct3D interface.

Example:

                                                                    cpp
IDirect3D9* d3d = Direct3DCreate9(D3D_SDK_VERSION);

This object is responsible for:

    Enumerating graphics adapters
    Querying device capabilities
    Creating rendering devices

4. Creating the Rendering Device

The device represents the GPU context used for rendering.

Example structure:

                                                                    cpp
D3DPRESENT_PARAMETERS d3dpp;
ZeroMemory(&d3dpp, sizeof(d3dpp));

d3dpp.Windowed = TRUE;
d3dpp.SwapEffect = D3DSWAPEFFECT_DISCARD;
d3dpp.BackBufferFormat = D3DFMT_UNKNOWN;

IDirect3DDevice9* device;

d3d->CreateDevice(
    D3DADAPTER_DEFAULT,
    D3DDEVTYPE_HAL,
    hWnd,
    D3DCREATE_HARDWARE_VERTEXPROCESSING,
    &d3dpp,
    &device
);

The device manages:

    Rendering state
    Resources
    Draw calls

5. The Rendering Pipeline

Direct3D 9 processes geometry through a series of stages:

    Input Assembly
    Vertex Processing
    Primitive Assembly
    Rasterization
    Pixel Processing
    Output Merger

In older fixed‑function pipelines, lighting and transformations were handled automatically.

More advanced applications use programmable shaders.
6. Vertex Buffers

Vertex buffers store geometry data in GPU memory.

Example vertex definition:

                                                                    cpp
struct Vertex
{
    float x, y, z;
    DWORD color;
};

Creating a vertex buffer:

                                                                    cpp
device->CreateVertexBuffer(
    sizeof(Vertex) * 3,
    0,
    D3DFVF_XYZ | D3DFVF_DIFFUSE,
    D3DPOOL_MANAGED,
    &vertexBuffer,
    NULL
);

7. Rendering Geometry

Typical rendering loop:

                                                                    cpp
device->Clear(...);

device->BeginScene();

device->SetStreamSource(...);
device->DrawPrimitive(...);

device->EndScene();

device->Present(NULL, NULL, NULL, NULL);

Steps involved:

    Clear frame buffer
    Submit geometry
    Execute draw calls
    Present frame to screen

8. Textures

Textures provide surface detail for 3D objects.

Creating a texture:

                                                                    cpp
D3DXCreateTextureFromFile(
    device,
    "texture.png",
    &texture
);

Textures can be applied during rendering using texture stages or shaders.
9. Lighting

The fixed‑function pipeline supports built‑in lighting models:

    Directional lights
    Point lights
    Spotlights

Lighting calculations can also be performed in shaders.
10. Shaders (HLSL)

Direct3D 9 introduced programmable shaders.

Types:

    Vertex Shader
    Pixel Shader

Example HLSL vertex shader:

                                                                    hlsl
float4 main(float4 position : POSITION) : SV_POSITION
{
    return position;
}

Shaders allow custom effects such as:

    Normal mapping
    Shadow mapping
    Post‑processing

11. Resource Management

Direct3D resources include:

    Textures
    Buffers
    Surfaces
    Shaders

Resources can exist in different memory pools:

    Default
    Managed
    System memory

Handling device loss is important in Direct3D 9 applications.
12. Device Loss Handling

If the device becomes lost (e.g., window focus change), the application must reset it.

Typical workflow:

    Detect device loss
    Release certain resources
    Reset the device
    Recreate resources
